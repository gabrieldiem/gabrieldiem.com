Standing orders for anything with a model in it

  1. Assume the replica dies mid-conversation.State lives outside the process. LangGraph checkpoints in Postgres at Auronix, Redis and Blob Storage at Pyyne.
  2. Send each task to the cheapest model that can do it.The biggest model doesn't always win anyway. The tuner below has the numbers.
  3. If you can't trace it, don't ship it.Langfuse on agent runs and tool calls, before anyone asks why it did that.
  4. Test against real inference.Integration tests that call the live LLM in CI. Slower and more expensive, and they catch what mocks can't.
  5. Keep one running at home.Ollama and llama.cpp for the bench, local Whisper for transcribing audio.
  6. Put it where people already work.Teams, for the agent at Pyyne. AIforce, now.
  7. Make the agents keep the docs.Custom skills with scripts, examples and a style guide, so the documentation and diagrams stay current.
